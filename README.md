# gabrain

A personal collection of stack-agnostic Copilot skills and rules for clearer reasoning, code walkthroughs, skill auditing, and consistent agent behavior.

## Included

- `how`: traces how code works and produces a focused walkthrough
- `skill-audit`: checks whether skills were used properly in a session
- `restate`: rewrites the last message in plain language
- Copilot rules for evidence, safety, judgment, and consistent behavior

## Install

```powershell
copilot plugin install geapostolopoulos/gabrain
```

Verify the skills in a new Copilot session:

```text
/skills list
```

## Update

Install the repository again after changes:

```powershell
copilot plugin install geapostolopoulos/gabrain
```
